Project Show-off

Project Show-off is an 8-week project in the second year of the study Creative Media & Game Technologies. This was the first time I got to work for a client. Our client asked for an interactive 3D application that could be accessed by scanning a QR-code.

The most important thing I learned from this project was working with different engines and programming languages. We took the time to figure out which platform would be best to build this application. We figured Unity would be too heavy to run in a mobile browser, so we started out using Babylon.js, a JavaScript based framework for 3D web applications. This turned out to be too complicated as our progress was too slow, so we decided to switch to game engine Godot, which can run in the browser and is easy to work with.

Tools and languages
  • Babylon.js
  • JavaScript
  • Godot
  • GDScript

The xylotheque

A xylotheque is a collection of wooden 'books' that have samples of different parts of a specific tree inside. With this application we use one tree as an example, to show how all parts of a xylotheque 'book' come together.
